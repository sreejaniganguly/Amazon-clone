# Amazon Homepage Clone

A frontend cole project recreating the Amazon homepage using just HTML and CSS.

## Technologies Used
- HTML
- CSS

## Website Preview

- Amazon-style navigation bar
- Search bar
- Hero section
- Category cards
- Foot section

## Purpose
This project was created for learning and practicing HTML and CSS.
